# 🔎 EVM Address Checker

A simple browser-based validator for Ethereum and EVM-compatible blockchain addresses.

## 🚀 Live Demo

[Open EVM Address Checker](https://nikatose.github.io/evm-address-checker/)

## ✨ Features

- Validate EVM address format
- Detect lowercase / uppercase / mixed-case addresses
- Works with Ethereum-compatible addresses
- No wallet connection required
- No API keys
- No backend
- No data storage
- Runs entirely in the browser

## 🧠 What It Checks

The tool verifies that an address:

- Starts with `0x`
- Contains exactly 40 hexadecimal characters
- Uses a valid EVM address format
